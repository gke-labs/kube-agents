# Whole-cluster kubectl reads under agents/ that were there when
# scripts/check_cluster_reads.py arrived, pinned at the count each file had
# that day. One entry per line: `<path> <rule> <count> <reason>`, the path
# relative to the repository root, the rule as the check reports it
# (`multi-kind-dump` or `unpaged-list`), the count above zero, the reason the
# rest of the line.
#
# The list only shrinks. The check fails when a file has more findings than
# its entry (a rise), when it has fewer (lower the count, or remove the entry
# once the file is clean), when an entry names a file the check does not
# scan, repeats a file and rule, names another rule, or is not an entry. A
# file with no entry is held at zero, so a new whole-cluster read anywhere is
# a failure, never a new line here.
#
# Every read below is one the pagination conversion of the collectors and
# the SOPs replaces with a paged or per-kind read; an entry leaves this file
# when its read is converted. `python3 scripts/check_cluster_reads.py --counts`
# prints the first three fields for the tree as it stands.
