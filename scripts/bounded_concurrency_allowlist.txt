# Functions that started an unbounded thread or goroutine per request when

# that day. One entry per line: `<file> <function> <count>`, the file relative
# to the repository root, the function as the check names it (`Class.method`
# for a method), the count above zero. The comment above an entry names the
# issue that owns the fix, or the bound the check cannot see. The rules (the
# list only shrinks: a rise, a drop, a stale entry, an entry for a file the
# check does not read, and a line that is not an entry all fail) are in the
# script's docstring; this file states only what is pinned and why.
