# for a method), the count above zero, and the issue that owns the fix in a
# comment above it.

# The list only shrinks. The check fails when a function has more unbounded

# file the check no longer sees a finding in, and when a line is not an entry.
# A function with no entry is held at zero, so a new per-request spawn anywhere
# the check reads is a failure, never a new line here.
