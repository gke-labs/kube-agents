## Prioritized SRE Remediation Plan

### Priority 1 — Security & Identity Hardening

- `payments/checkout` mounts a static service account key for a project-editor service account from
  the Secret `checkout-gcp-key`. Anyone who can read that Secret holds editor on the project. Move
  the workload to Workload Identity and delete the key. (severity: high)
- Workload Identity is disabled on `prod-east`, which is why workloads there authenticate with
  exported keys. Enable it on the cluster and its node pool. (severity: high)

### Priority 2 — Workload Reliability & Probes

- `payments/cart` has no readinessProbe, so a replica still warming up receives traffic. Add one.
  (severity: medium)
- `web/frontend` has no readinessProbe either. Add one. (severity: medium)
- `data/orders-db` sets memory requests but no memory limit, so it can take memory from its
  neighbours until the node evicts them. Set a limit. (severity: medium)

### Priority 3 — Observability & Telemetry

- Managed Service for Prometheus is not enabled on `prod-east`; nothing collects workload metrics.
  Enable it. (severity: low)
