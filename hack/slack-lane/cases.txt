# thing only real Slack shows. Each runs once through Slack (AGENT_TRANSPORT=slack);
# the case grades the first turn as it does on inject, where it keeps its own
# nightly record, and the lane adds Slack's own timings. Advisory: the lane gates
# nothing. ci-kube-agents-eval-nightly-slack runs them one at a time.
#
# "<case id>" runs one turn. "<case id> then: <reply>" sends <reply> in the
# thread once the first turn settles and records how that second turn went

# turn's reply, but its checks run after the second turn, so a safeguard sees
# anything the second turn changed. A question is answered by typing: Slack's

# are ignored, and a reply may hold a "#".
#
# A case that checks a worker's tool calls cannot pass here (the transport
# records no trajectory).
