# The inject lane's exclusions: registered cases that do not run when the
# matrix goes through the A2A gateway's inject door (the harness's
# AGENT_TRANSPORT=inject, which hack/ci-eval-pr.sh exports under
# EVAL_MODE_NEXT=1 except on the today lane), because the case's premise needs something the door
# does not carry: a specialist's answer folded back into the chat thread, or
# a card's wake, which the harness replays on the api transport only.
#
# One case id per line; `#` starts a comment, blank lines are skipped. The
# reason is the comment block directly above the id, and it names the issue
# that decides when the entry goes: scripts/test_eval_rosters.py fails an
# entry with no reason, with no issue number, or that names no registered
# case. hack/ci-eval-pr.sh reads this file when it builds the matrix and,
# only under AGENT_TRANSPORT=inject, drops the named cases from TASKS before the fan-out
# and says so in the log; on the api transport the file changes nothing,
# and the api lane's rosters (presubmit-cases.txt, blocking-roster.txt,
# nightly-cases.txt) are untouched. An entry still takes a case out of CI:
# the nightlies grade over inject, and the only api-transport job on main is
# the today lane (ci-kube-agents-eval-today), which runs the presubmit matrix,
# so a listed presubmit case runs there and a listed nightly case runs
# nowhere. The
# same shape as the validator's FIXTURE_NOT_READY: an exclusion with a
# reason, not a marker on the case (docs/eval-gate-roster.md, "The inject
# lane").
#
# What does NOT belong here: a case whose only problem on the inject lane is
# a `worker_commands`, `worker_agents` or `worker_budget` check, or a `tool_called` check on
# a door that shows no tool-call trace. The scorer sets such a check aside
# as not applicable on that transport and grades the rest, so the case
# still runs and still reports (docs/designs/eval-scorer.md). An entry here
# is for a premise the transport removes, not a check it blinds.
#
# WHO APPROVES. The eval crew, as for presubmit-cases.txt: the merge-blocking
# presubmit runs on the inject lane, so an entry takes a case out of every
# pull request's matrix and, for a blocking-roster case, out of what can red
# one; hack/OWNERS scopes this file to the eval-crew alias.
