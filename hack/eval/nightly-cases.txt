# The nightly-only eval cases: what the nightly runs on top of the presubmit.
#
# One `./tasks/<id>/task.yaml` path per line, relative to bench/. `#` starts
# a comment, blank lines are skipped. hack/ci-eval-pr.sh reads this file at
# startup into NIGHTLY_TASKS and, under EVAL_TIER=nightly (exported by the
# Prow periodic ci-kube-agents-eval-nightly and nothing else), appends it to
# the presubmit matrix in this order, so the nightly is a superset of the
# presubmit by construction and a case in presubmit-cases.txt runs
# identically in both. The script refuses to start on a line that names no
# case directory or that is also in presubmit-cases.txt (it would run twice a
# night). The registration lint (scripts/validate_bench_cases.py) reads this
# file as well as the presubmit one; the domain-coverage lint deliberately
# does not, so an entry here satisfies presubmit domain coverage not at all.
#
# WHO APPROVES. The normal approvers (root OWNERS). Only the presubmit files
# beside this one carry the eval-crew rule (#1546, decided 2026-09-15).
#
# WHAT BELONGS HERE. Every registered case that is not in the presubmit and
# has a fixture -- this is the default home for a new case (decided
# 2026-09-15 on #1546 and #1564): it lands here, the nightly builds its
# record in the evidence store, and a presubmit seat is a later pull request
# that cites that record. Measured cost, presubmit redundancy and grading
# something outside the core journeys keep a case here for good. The rule
# this file's predecessor carried -- a case that fails on a correct agent
# stays commented out because the nightly appends to the evidence store --
# is retired: a case that can only fail appends evidence that keeps it out
# of the presubmit, which is what the record is for, and the ~10 minutes of
# matrix it costs a night is bought back by the wider fan-out. The one case
# that stays out is one whose fixture does not exist at all; it waits in the
# validator's FIXTURE_NOT_READY allowlist with the issue that plants it, and
# today that is obtainability-declared-intent-no-finding (#1341, needs a
# second multi-replica workload as a role of its own plus a declaration
# seeded in each pool project's *-infra repository) and vcs-history-only-fact
# (#1253, needs the git-access-ab/r200 branch pushed to every pool
# project's GitOps repository).
#
# BUDGET, priced the way EVAL_REPETITIONS' comment in the script prices the
# presubmit. The twenty-six-case matrix of 2026-09-09 priced at ~532-552min
# SERIAL at three repetitions: the eighteen-case presubmit (~211min), the
# two tofu incumbents (~106min, #1218), the four audit-shaped recasts hinted
# at 900s in unit_cost_hint (~190min with the probe-shaped fifth), and
# knowledge-grounding-sources-probe (~25-45min, #945). 2026-09-15 added
# eleven: #1079's two (chat-routing-board-read ~10min, pdb-remediation-pr
# ~63min at its 1250s hint) and the nine this decision moved here, of which
# eight are deployer: noop and probe-shaped (~200s a repetition, ~10min each
# at three) and fleet-cost-idle-pool is a full cost audit priced with the
# 900s audit band (~45min). 2026-09-16 added incident-triage-oom-event-probe
# (#1023, ~45min at its measured 737s/599s/1357s). 2026-09-21 added #1103's
# two tofu cases (ai-security-planted-model-audit ~73min at its 1450s hint,
# autoops-crashloop-config-triage ~45min at the 900s band; both serialize on
# the infra lock with the two incumbents). Forty-one cases, ~893-913min
# serial. The
# periodic runs at 00:00 UTC -- 8 PM EDT, after the working day's presubmit
# herd -- with a 480m deadline, EVAL_TASK_PARALLELISM=6 and EVAL_REPETITIONS
# at its default 3 (#1491). At the ~1.15x the presubmit realised on
# whole-job wall clock at parallelism 4 under daytime quota contention that
# would be ~775-795min, over the deadline; 480m holds only if the nightly,
# alone on the model quota at that hour and two lanes wider, realises ~1.9x
# or better. Night one (2026-09-16, build 2100374258805903360, #1491)
# realised 5.57x on the thirty-nine-case matrix and used 71% of the budget,
# so the two additions are priced inside its headroom. The first nights after this change measure it:
# record the wall clock and any truncation on #1491, and if the deadline
# bites, the lever is the periodic's timeout or this list's tail, in that
# order. A deadline kill is survivable by design -- the cost-hinted queue
# means it truncates in-flight units, the EXIT trap still records what
# completed -- but it is a truncated night.
