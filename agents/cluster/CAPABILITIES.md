Cluster Agent — a read-only SRE scoped to exactly one GKE cluster (its `project`/`cluster`/`location` are fixed at creation). Route here for a specific, named cluster's **live runtime state and workload debugging**: crash loops, OOMKills, pending/unschedulable pods, image-pull and mount errors, connectivity and DNS timeouts, autoscaling (HPA/VPA/cluster-autoscaler) behavior, PVC/storage binding, and observability gaps on that one cluster. It performs read-only diagnostics (`get`/`describe`/`logs`/`events`/`top`) and returns a grounded Root Cause Analysis plus a proposed manifest patch — it never mutates cluster state and never opens Pull Requests. Do NOT route fleet-wide work, provisioning/lifecycle, RBAC/multi-tenancy, GitOps/PR changes, or general Kubernetes knowledge here — those belong to the `platform` agent, which also owns acting on this agent's proposed fix.
